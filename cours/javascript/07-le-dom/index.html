Le DOM : sélectionner et modifier la page

要 L’essentiel en 30 s

Le DOM, c'est la page HTML vue par JavaScript : un arbre d'objets. On sélectionne un élément (getElementById, querySelector), puis on change son texte (textContent), ses classes (classList) ou son style. On peut aussi créer des éléments, les ajouter et les supprimer.

覚 À retenir

  • getElementById("id") sans dièse ; querySelector("#id") avec, comme en CSS.
  • Pour afficher une saisie, textContent, jamais innerHTML (faille XSS).
  • Préfère classList à style : l'apparence reste dans le CSS.
  • Les valeurs de dataset sont toujours des chaînes.
  • Un élément créé avec createElement n'apparaît qu'une fois ajouté avec appendChild.

Sélectionner un élément

何Quoi

Avant de modifier, il faut sélectionner. getElementById("id") cherche par id. querySelector("sélecteur") renvoie le premier élément qui correspond. querySelectorAll les renvoie tous, dans une NodeList.

罠Piège

getElementById s'écrit sans dièse (getElementById("miroir")), querySelector avec (querySelector("#miroir")). Si rien ne correspond, les deux renvoient null.

何Quoi

textContent lit ou remplace le texte d'un élément. innerHTML remplace son HTML : les balises sont interprétées. Pour un champ de formulaire, ce qui est tapé se lit avec value.

罠Piège

Changer l'apparence : classList et style

何Quoi

classList ajoute (add), retire (remove) ou bascule (toggle) une classe CSS. style modifie une propriété CSS directement, écrite en camelCase (backgroundColor).

罠Piège

Les attributs data- : dataset

何Quoi

Un attribut data-quelquechose range une information dans le HTML. En JavaScript, on la lit ou on l'écrit avec dataset.quelquechose.

罠Piège

辞

Définitions

DOM

Document Object Model : la page HTML représentée comme un arbre d'objets que JavaScript peut lire et modifier.

Élément HTML

Un nœud du DOM qui correspond à une balise : <p>, <button>, <img>…

Exemple

document.getElementById("miroir")

Sélecteur CSS

Texte qui désigne des éléments, comme dans une feuille de style : #id, .classe, balise, ou une combinaison.

Exemple

.miniatures img

textContent

Propriété qui lit ou remplace le texte brut d'un élément. Les balises éventuelles sont affichées telles quelles, pas interprétées.

Exemple

miroir.textContent = "Bonjour";

innerHTML

Propriété qui lit ou remplace le HTML d'un élément. Dangereuse avec une saisie de l'utilisateur.

Exemple

el.answers.innerHTML = "";

classList

Outil pour ajouter (add), retirer (remove) ou basculer (toggle) les classes CSS d'un élément.

Exemple

ampoule.classList.toggle("on")

dataset

Accès en JavaScript aux attributs data-* d'un élément. Les valeurs sont toujours des chaînes.

Exemple

btn.dataset.humeur

XSS (cross-site scripting)

Faille où un pirate fait exécuter son propre code dans la page, souvent via innerHTML rempli avec une saisie non filtrée.

Exercices

  1. Exercice 1Facile

    Le titre de la page

    La page contient <h1 id="titre">Bonjour</h1> et <p class="info">Texte</p>. Remplace le texte du titre par « Manabi », mets-le en vermillon (#C8382A) et ajoute la classe important au paragraphe.

  2. Exercice 2Moyen

    La liste de courses

    À partir de const courses = ["riz", "nori", "saumon"]; et d'une liste vide <ul id="liste"></ul>, crée un <li> par article.

  3. Exercice 3Difficile

    Les badges de priorité

    La page contient plusieurs <div class="card" data-priority="high"> (ou medium, low) et un <p id="compteur"></p>.

    Ajoute à chaque carte un <span> de classe priority high (selon sa priorité) qui affiche « Haute », « Moyenne » ou « Faible ». Écris ensuite dans le compteur le nombre de cartes urgentes, par exemple « 2 carte(s) urgente(s) ».
