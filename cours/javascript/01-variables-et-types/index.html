要 L’essentiel en 30 s

Une variable est une boîte avec un nom : const si tu ne la réassignes jamais, let si elle doit changer. Chaque valeur a un type (string, number, boolean…). prompt() renvoie une chaîne, jamais un nombre : convertis-la avec parseInt() ou Number() avant de calculer.

覚 À retenir

  • Par défaut, écris const ; passe à let seulement si la variable doit être réassignée.
  • typeof donne le type d'une valeur : "string", "number", "boolean"…
  • Dès qu'une chaîne est dans l'addition, + colle au lieu de calculer : "5" + 2 donne "52".
  • Les méthodes de chaîne (slice, trim, toLowerCase…) renvoient une nouvelle chaîne : elles ne modifient jamais l'originale.
  • Une conversion ratée donne NaN : vérifie avec Number.isNaN().

Calculer et tirer au hasard

何Quoi

Les opérateurs de calcul : + - * / et %, le reste de la division. L'objet Math fournit les outils : Math.floor() arrondit vers le bas, Math.random() donne un nombre entre 0 (inclus) et 1 (exclu).

例Exemple

罠Piège

Sans le + 1, Math.floor(Math.random() * 100) donne de 0 à 99. Et diviser par zéro ne plante pas : 5 / 0 donne Infinity.

辞

Définitions

Variable

Une boîte nommée qui garde une valeur pour s'en servir plus loin.

Exemple

let score = 0;

const

Déclare une variable qu'on ne peut pas réassigner. C'est le choix par défaut.

Exemple

const badgeNumber = 7;

Type

La nature d'une valeur : string (texte), number (nombre), boolean (vrai / faux), undefined, null, object…

Exemple

typeof 30 // "number"

Chaîne (string)

Une valeur de type texte, écrite entre guillemets ou entre accents graves.

Exemple

"Bonjour"

Concaténation

Coller des chaînes bout à bout avec l'opérateur +.

Exemple

"Il est " + heure + " heures."

Gabarit (template literal)

Chaîne écrite entre accents graves dans laquelle ${} insère une valeur.

Exemple

`Il est ${heure} heures.`

NaN

« Not a Number » : la valeur obtenue quand une conversion ou un calcul en nombre est impossible.

Exemple

parseInt("abc") // NaN

Modulo (%)

Opérateur qui donne le reste d'une division entière. Pratique pour savoir si un nombre est pair.

Exemple

7 % 2 // 1
