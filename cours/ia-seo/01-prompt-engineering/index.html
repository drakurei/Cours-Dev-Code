Prompt engineering : bien parler à une IA

  • 10 min
  • Débutant
  • 28 août 2026
  • Cours IA & SEO — atelier prompt engineering (todo list avec validation d'email)
0 %

要 L’essentiel en 30 s

Un bon prompt est un brief clair : un rôle, du contexte, une consigne précise et un format de sortie, plus un ou deux exemples si besoin. Ensuite, tu itères : un seul changement par message, jusqu'au bon résultat.

覚 À retenir

  • Rôle, contexte, consigne, format : les quatre blocs de base d'un prompt.
  • Des critères de réussite vérifiables : l'IA devine moins, et tu sais quand c'est réussi.
  • Un ou deux exemples valent mieux qu'une longue explication.
  • On itère avec un seul changement par message, en repartant du dernier résultat.
  • Le code d'une IA se relit et se teste : elle peut se tromper avec assurance.

Le rôle

何Quoi

Le rôle dit à l'IA quel expert elle doit être. Il fixe le niveau de la réponse et le vocabulaire employé.

例Exemple

罠Piège

Le rôle seul ne suffit pas : « Tu es un expert » sans contexte ni consigne donne une réponse générique.

場Dans Manabi

PROMPT-COURS.md commence par un rôle : « Tu es un pédagogue expert en développement ».

Le contexte

何Quoi

Le contexte, c'est tout ce que l'IA ne peut pas deviner : le projet, la stack, les contraintes et ce qui existe déjà.

例Exemple

罠Piège

Coller tout le projet « au cas où » noie l'information et coûte des tokens : donne seulement les fichiers utiles.

場TP films (API TMDB)

Préciser « HTML + SASS + JS natif en modules ES » évite que l'IA réponde avec du React.

技Astuce

Si tu ne sais pas quoi mettre, termine ton prompt par : « Pose-moi d'abord les questions qui te manquent. »

La consigne

何Quoi

La consigne est la tâche : un verbe d'action, une seule tâche et des critères de réussite vérifiables.

例Exemple

罠Piège

« Améliore le formulaire » n'est pas une consigne : l'IA choisit à ta place ce qu'« améliorer » veut dire.

場Atelier prompt engineering

C'est exactement ce que fait script.js : validateEmail, showEmailError et clearEmailError.

Le format de sortie

何Quoi

Le format décrit la forme de la réponse : quels fichiers, dans quel ordre, quelle longueur, avec ou sans explication.

例Exemple

罠Piège

Sans format, l'IA renvoie souvent un long texte avec des morceaux de code : tu ne sais plus quoi coller où.

場Dans Manabi

Le prompt de l'Atelier impose le format exact d'un cours (frontmatter puis notions) : c'est ce qui permet au site de le valider automatiquement.

Les exemples (few-shot)

何Quoi

Donner un ou deux exemples d'entrée et de sortie attendue : l'IA imite le modèle. C'est le few-shot.

例Exemple

罠Piège

Des exemples trop semblables enferment l'IA : varie-les, avec au moins un cas normal et un cas limite.

場Atelier prompt engineering

Pour faire générer les tests de la fonction validateEmail de script.js.

L'itération

何Quoi

Un premier résultat est rarement parfait. Tu itères : un seul changement par message, en repartant de ce que l'IA vient de produire.

例Exemple

罠Piège

Tout demander d'un coup (email, tri, thème sombre et sauvegarde) produit un gros bloc de code difficile à relire et à tester.

場Atelier prompt engineering

La todo list se construit par étapes : la liste, puis l'email, puis le vérificateur d'email.

辞

Définitions

Prompt

Le message (consigne et informations) que tu envoies à une IA pour obtenir une réponse.

Prompt engineering

L'art de rédiger et d'améliorer ses prompts pour obtenir des réponses fiables et directement utilisables.

Rôle (persona)

Le métier ou le point de vue que tu demandes à l'IA d'adopter, par exemple « développeur front-end senior ».

Contexte (prompt)

Les informations que l'IA ne peut pas deviner : le projet, la stack, les contraintes, le code existant.

Critère de réussite

Une condition vérifiable qui dit quand la tâche est réussie.

Exemple

Le message d'erreur disparaît dès que l'utilisateur retape dans le champ.

Few-shot

Technique qui consiste à donner quelques exemples d'entrée et de sortie attendue dans le prompt, pour que l'IA imite le modèle.

Itération (prompt)

Améliorer la réponse d'une IA par messages successifs, en corrigeant un seul point à la fois.

Hallucination

Une réponse fausse donnée avec assurance par une IA : fonction qui n'existe pas, chiffre inventé, source imaginaire.

練

Exercices

Essaie d’abord seul. Ouvre un indice seulement si tu bloques.

  1. Exercice 1Facile

    Muscler un prompt vague

    Réécris le prompt « fais-moi une todo list » avec les quatre blocs : rôle, contexte, consigne et format.

  2. Exercice 2Moyen

    Des messages de commit par l'exemple

    Écris un prompt few-shot : deux exemples de messages de commit au format « type: description » (en français, courts), puis la demande pour ton nouveau changement : l'ajout d'un champ email facultatif dans la todo list.

  3. Exercice 3Difficile

    Tester la regex avant d'itérer

    Dans l'atelier, l'IA a produit EMAIL_REGEX. Écris un script Node qui teste six adresses (trois valides, trois invalides) et affiche OK ou ÉCHEC. Trouve une adresse invalide que la regex accepte, puis écris le prompt d'itération qui demande la correction.
